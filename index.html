BUILDING · 2026card_01 · case study

          
DevLens

          
Privacy-first debugging assistant for engineering teams.

          
Teams connect Slack, GitHub, Jira, Google Drive and code folders, or import chat exports and logs. A deterministic Privacy Gateway (secret scanning, Presidio PII, name hashing) runs before any content reaches an LLM, and LangGraph orchestrates streamed root-cause reports where every claim must quote its evidence and be judged to support it.

          

            

              
what_it_does

              
    
                
  • Cited chat over project knowledge, streamed over SSE
    • 
                
  • Root-cause debug reports with claim verification
    • 
                
  • Incident timelines → Markdown postmortems
    • 
                
  • Code awareness: answers cite file + line, linked to the commit
    • 
                
  • Weekly digests, “knowledge gaps” to import next
    • 
                
  • Insights: usage, cost, budgets, answer quality, eval runs
    • 
              

            

            

              
how_it's_built

              
    
                
  • FastAPI + async SQLAlchemy, Alembic migrations
    • 
                
  • LangGraph workflow + Postgres checkpointer with retention
    • 
                
  • pgvector retrieval plus exact identifier matches, project-scoped in SQL
    • 
                
  • arq on Redis for syncs, digests, evals; Redis rate limiting
    • 
                
  • OAuth 2.0 “Connect with…” for 4 providers, encrypted refreshing tokens
    • 
                
  • Argon2, JWT + rotating refresh sessions, admin/member/viewer RBAC, audit log
    •
